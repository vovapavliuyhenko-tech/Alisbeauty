# Журнал изменений — сайт A'LIS Beauty

## 2026-07-29 — Полный редизайн: переезд с Tilda на Next.js

Старый статичный прототип удалён (сохранён в истории git). Сайт переписан с нуля
по ТЗ: премиальный одностраничник с якорной навигацией.

**Стек:** Next.js 15 (App Router) + TypeScript, Tailwind CSS, next-intl (RU/EN),
Framer Motion (анимации), Lenis (плавный скролл), embla-carousel, lucide-react.

**Сделано:**
- Двуязычность RU/EN (мгновенное переключение, hreflang, весь текст в `messages/*.json`).
- Дизайн-система: тёмная премиум-палитра, токены в `globals.css`, шрифты Playfair Display + Manrope.
- Шапка: прозрачная → с фоном при скролле, scroll-spy, мобильный drawer, переключатель языка.
- Кнопка «Записаться» → модалка выбора Telegram / WhatsApp.
- Секции: Hero (выбор Салон/Консьерж), О салоне, Основатель, Консьерж-сервис,
  Уникальность (01–05), Полный образ, Как заказать (01–03), Наши работы, Галерея,
  Отзывы (слайдер), Прайс, Анкета, Контакты, Footer.
- Анимации: reveal-on-scroll, стаггеры, кинетические заголовки, параллакс hero,
  уважение к `prefers-reduced-motion`.
- Формы: две анкеты (По России / За рубеж) с валидацией, honeypot + time-trap.
  API-роут `/api/enquiry` шлёт заявку в Telegram и на email (Resend).
- Галерея: masonry + фильтры по категориям + lightbox (фото/видео).
- Лента Instagram: `/api/instagram` (Graph API, кеш 1 час) с запасным вариантом без токена.
- SEO: метаданные, OG, favicon, sitemap.xml, robots.txt, canonical, hreflang.
- Яндекс.Метрика (по env) + цели: открытие «Записаться», отправка формы.
- Страница `/politic` (политика конфиденциальности — заглушка).
- README с инструкцией по env и деплою на Vercel.

**Проверено:** `npm run build` — успешно; RU и EN отдаются (200); лента IG —
корректный запасной режим без токена.

### Что нужно от заказчика
- Логотип (SVG/PNG), фирменный шрифт, реальные фото/видео в галерею.
- Заполнить `.env.local`: Telegram (токен + chat_id), Resend (email),
  Instagram (токен + user_id), номер Яндекс.Метрики.
- Финальные цвета (сейчас — дефолтная премиум-палитра).
- Доступ к домену `alisbeauty.ru` для подключения на Vercel.
