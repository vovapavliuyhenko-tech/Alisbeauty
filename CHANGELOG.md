## 2026-07-28 — Первая версия (каркас сайта)

Создан статичный сайт-визитка салона красоты с онлайн-записью.

**Структура файлов:**
- `index.html` — все секции сайта на одной странице
- `css/style.css` — стили и адаптив (мобильная версия)
- `js/main.js` — мобильное меню + обработка формы записи

**Стиль:** нежный бежево-розовый, шрифты Cormorant Garamond + Jost.

## 2026-07-28 — Форма записи: отправка в Telegram

Добавлена отправка заявок с формы в Telegram-бота.

- `js/config.js` — новый файл с токеном бота и chat_id (пока пустые).
- `js/main.js` — форма отправляет заявку через Telegram Bot API.
  Пока config.js не заполнен — работает тестовый режим (заявка не уходит).

### Как настроить Telegram (инструкция)
1. В Telegram открыть @BotFather → команда `/newbot` → получить ТОКЕН.
2. Написать своему боту любое сообщение.
3. Открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найти `"chat":{"id":...}` — это chat_id.
4. Вписать ТОКЕН и chat_id в файл `js/config.js`.

Примечание: на статичном сайте токен бота виден в коде страницы.
Для полного сокрытия токена нужен серверный обработчик (обсудить при необходимости).
